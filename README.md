# TTOD

**TTOD (That Time of Day)** is a simple, privacy-first menstrual cycle and wellness tracker built with Flutter.

## Features
- **Cycle Tracker & Calendar**: Log periods, flow intensity, and symptoms with an easy month-by-month calendar and clear next-period & fertile-window predictions.
- **Phase-Matched Nutrition**: Personalized food and nutrient guidance tailored to your current cycle phase, plus a searchable cookbook of 100 wellness recipes.
- **Community**: Share thoughts, tips, and support with others.
- **Private & Offline-First**: Use the app offline without an account; cycle records are stored locally on your device using Hive with one-tap JSON backup.

## Getting Started

```bash
flutter pub get
flutter run
```

## Running Tests

```bash
flutter test
```
