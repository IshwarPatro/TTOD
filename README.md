# TTOD

**TTOD (That Time of Day)** is a simple, privacy-first menstrual cycle and wellness tracker built with Flutter.

## Features
- **Cycle Tracker & Calendar**: Log periods, flow intensity, and symptoms with an easy month-by-month calendar and clear next-period & fertile-window predictions.
- **Invite-Only Group Chat & Friends**: Create private groups (with auto-generated avatar & description if omitted), invite friends via link or QR code, manage `Admin` and `User` roles, approve join requests, and keep a friend list — protected by built-in anti-abuse rate limits.
- **Private & Offline-First**: Use the app offline without an account; cycle records are saved automatically on your device using Hive.

## Getting Started

```bash
flutter pub get
flutter run
```
