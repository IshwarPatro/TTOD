Technical Design & Implementation Plan

Phase-by-phase design document for Firebase Authentication, Social Forums, Offline LLM integration, and AI Profile image generators.

🎨 Liquid Glass Design System

A translucent glass design system utilizing light refraction, blur, and color overlay tokens.

  • Base Palette: Cream-Yellow (#FFF4BF), Lavender (#FFBEFB), Lilac (#DC95FF), and Deep Amethyst (#8C56D4).
  • Specular Highlights: Accomplished by applying 1.5px borders of #DC95FF with opacity to card edges.
  • Refraction Backdrop: Utilizing real-time BackdropFilter with 18px blur sigma overlaying #FFBEFB with 35% opacity.

Phase 2

True Offline AI Chatbot Model

Deploy a fine-tuned, quantized Large Language Model running fully on-device on client resources, avoiding cloud billing dependencies.

1. Model Training Flow

  • Model Base: Use high-performance ultra-small models: Llama-3.2-1B-Instruct or Gemma-2B-IT.
  • Domain Fine-Tuning: Build a custom dataset of 5,000 wellness cycles conversation-answer pairs. Train utilizing QLoRA adapters.
  • Model Quantization: Quantize the PyTorch model weights down to 4-bit (Q4_K_M GGUF) via llama.cpp toolchain. This reduces size to ~850MB, making local loading fluid.

2. On-Device Execution

Utilize llama.cpp native bindings via flutter_rust_bridge to run GGUF query inference directly in C/C++/Rust on the mobile device GPU/CPU.

Phase 3

AI Profile Photo Generator

Generate highly stylized profile illustrations from text prompts using an authenticated text-to-image API.

Implementation Blueprint

  • Training custom LoRA: Compile a static dataset of 30-50 illustrations showing a unified vector wellness art style. Train a LoRA adapter on top of Stable Diffusion XL (SDXL).
  • Serverless Hosting: Host the adapter and base model on Replicate or Fal.ai serverless GPUs.
  • Storage integration: Wrap user submission prompts inside a default style filter. Send requests, fetch the png output, save it in Firebase Storage, and reference the URL inside the user's Firestore index.
